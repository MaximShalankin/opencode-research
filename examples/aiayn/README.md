# Пример: «Attention Is All You Need»

Снимок `workspace/` после прогона агента (OpenCode + Qwen3.8-27B) на
масштабированной постановке: Multi30k en→de, малый Transformer
(2 слоя, d_model 256, 4 головы), 30 эпох на одном GPU.

**Результат:** val BLEU 23.27 (эпоха 26), **test BLEU 22.11** (sacreBLEU
13a), обучение ~105 с, 7.82M параметров. Числа статьи (27.3/28.4 BLEU на
WMT14) — только ориентир, это другая постановка.

## Что внутри

| Файл | Что это |
|---|---|
| `workspace/recipe.json` | 17 полей рецепта из статьи, у каждого — страница `p. N` |
| `workspace/PLAN.md` | план агента: стадии, бюджеты, риски |
| `workspace/model.py`, `bpe.py`, `train.py` | код: Transformer, BPE, обучение и оценка |
| `workspace/metrics.json` | конфиг и метрики из реального запуска |
| `workspace/REPORT.md` | отчёт «утверждение → значение → доказательство» |

## Как воспроизвести

1. Разверните память и проиндексируйте статью — [docs/memory.md](../../docs/memory.md).
2. Положите Multi30k в `data/multi30k/` (ссылка и sha256 — там же).
3. Из корня репозитория запустите агента с `task.md`; артефакты появятся
   в `workspace/`.

Чтобы запустить код без агента, скопируйте `workspace/` в корень
репозитория и выполните `cd workspace && python3 train.py`. Нужны пакеты
`torch`, `tokenizers`, `sacrebleu`, `numpy`.

## Примечания

- Артефакты приведены как есть, включая огрехи агента: в `PLAN.md` есть
  опечатки, а `REPORT.md` честно фиксирует четыре исправления кода,
  которые потребовались после генерации.
- Логи обучения и внутренний эталонный прогон в репозиторий не входят;
  `REPORT.md` ссылается на них как на доказательства.
